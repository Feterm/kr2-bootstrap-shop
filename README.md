## Дополнительные доработки для контрольной работы

1. **Поиск и фильтрация программ** — поиск по названию и описанию, фильтр по категории и возрастному ограничению, сортировка по цене, длительности и возрасту.
2. **Избранные программы** — добавление и удаление программ из избранного. Список сохраняется в `localStorage`.
3. **Сравнение программ** — сравнение до трёх программ по цене, продолжительности, возрасту, категории, формату и расписанию.
4. **Недавно просмотренные программы** — автоматическая история последних четырёх просмотренных программ с возможностью очистки.
5. **Проверка свободных мест** — отображение остатка мест для выбранной программы, даты и времени; демонстрационные бронирования сохраняются в `localStorage`.

### Файлы новых функций

- `js/catalog-enhancements.js` — поиск, фильтры, избранное, сравнение и история просмотров.
- `js/ticket-capacity.js` — проверка доступности мест и демонстрационная бронь.
- `css/custom.css` — стили новых элементов интерфейса.

**Примечание:** проект статический и работает на GitHub Pages. Поэтому доступность мест и бронирования являются демонстрационными и хранятся отдельно в браузере пользователя. Для общей онлайн-брони между разными устройствами потребуется сервер и база данных.


## Фирменный стиль и контакты

Во всех HTML-страницах унифицированы шапка и подвал в компасной стилистике. Добавлен блок «О компании» на главной странице и ссылки на поиск адреса в Яндекс Картах.

**Важно:** телефон, почта и адрес в подвале являются демонстрационными данными учебного макета. Перед реальным запуском замените их на подтверждённые контакты организации. Ссылка Яндекс Карт открывает поиск демонстрационного адреса «Москва, ул. Звёздная, 1», а не подтверждённую геолокацию действующего планетария.
